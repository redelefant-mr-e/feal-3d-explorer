# FEAL 3D-Explorer

Interactive 3D product explorer for the FEAL IRV242 two-piece vehicle loading ramp.

**Live site:** https://redelefant-mr-e.github.io/feal-3d-explorer/

This repository hosts the static build for [GitHub Pages](https://pages.github.com/). The application is self-contained (Three.js vendored locally; no CDN or backend).

## Local preview

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory .
```

Then open http://127.0.0.1:5173
